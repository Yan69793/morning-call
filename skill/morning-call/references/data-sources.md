# Fontes de Dados

**A matriz de fontes vive em `docs/DATA_SOURCES.md`, na raiz do repositório.** Leia lá.

Este arquivo era uma cópia com 174 linhas de endpoints verificados — e era a melhor versão que
existia, melhor que a do próprio repositório. Esse é justamente o problema: o documento de maior
alavancagem do projeto morava no lugar que ninguém tinha declarado canônico, e as duas versões já
discordavam.

O conteúdo foi absorvido para `docs/DATA_SOURCES.md`. Aqui fica só o ponteiro, porque duas cópias
de uma matriz de endpoints envelhecem em direções diferentes exatamente como dois schemas.

Se você está lendo isto fora do repositório e não alcança `docs/`, saiba que qualquer cópia local
seria uma foto de uma data que você não sabe qual é — o mesmo defeito que o `_RJ_FLOOR` do VIX
Radar tem, e que este projeto existe para não cometer.
